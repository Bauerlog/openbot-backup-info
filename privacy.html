Privacy Policy - OPENBOT BACKUP

Last updated: November 25, 2026

Purpose

OPENBOT BACKUP is a personal, non-commercial backup and recovery application intended solely for its owner.

Google Drive access

The application uses the Google Drive API to create, read, verify, download and delete authorized backup files and their associated metadata.

Data usage and storage

Data is used exclusively for backup, integrity verification and disaster recovery. Backup files are encrypted locally using Restic before being transferred to the owner's Google Drive account.

Data sharing

Google user data is not sold, used for advertising, shared with unrelated third parties or used to train artificial intelligence models.

Security

OAuth credentials and encryption passwords are stored in access-restricted files. Backup transfers use encrypted connections.

Retention and deletion

Backups are retained according to the retention settings selected by the owner. The owner can delete backup files and local copies, and revoke authorization through Google Account settings.

Google API compliance

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions may be submitted through the project repository. Do not include credentials or confidential information.
