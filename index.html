OPENBOT BACKUP

OPENBOT BACKUP is a personal, non-commercial automated backup system for protecting and recovering application data.

Purpose

The system uses Restic for encrypted backups and Rclone to transfer encrypted backup files to the owner's Google Drive account.

Personal use

This application is intended exclusively for its owner and is not offered as a public service.

Data protection

Backup data is encrypted locally before being transferred to Google Drive.
